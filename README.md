# Vault Cleaner · Destiny 2

Extensión para Firefox y Chrome que ayuda a revisar el inventario de Destiny Item
Manager (DIM). Sincroniza las notas de light.gg, compara duplicados y permite
preparar lotes de transferencia para revisar antes de enviarlos.

La versión actual es **0.3.7**. Los iconos de sincronización y recarga están
junto al botón de cierre del panel.

## Instalación

- **Firefox:** el [paquete para Mozilla](packages/Vault-Cleaner-v0.3.7-Firefox-AMO.zip)
  se puede enviar junto al [código fuente para revisión](packages/Vault-Cleaner-v0.3.7-Firefox-Source-AMO.zip).
  Para una instalación permanente, usa el XPI firmado que entrega Mozilla.
- **Chrome:** en `chrome://extensions`, activa el modo de desarrollador y carga
  [la carpeta Chrome](Chrome/) como extensión descomprimida. También puedes usar
  el [ZIP de Chrome](packages/Vault-Cleaner-v0.3.7-Chrome.zip).
