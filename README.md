# Vault Cleaner · Destiny 2

Vault Cleaner is a Firefox and Chrome extension that helps you review and
organize your Destiny 2 inventory in Destiny Item Manager (DIM). It syncs
light.gg ratings, compares duplicate copies, and lets you review transfer batches
before sending them.

In **v0.3.7**, the light.gg sync and inventory refresh icons are next to the
panel's close button.

## Install

- **Firefox** — Download the [signed Firefox XPI](https://github.com/SebasCH04/Vault-Cleaner/releases/download/v0.3.7/Vault-Cleaner-v0.3.7-Firefox.xpi).
  Open `about:addons`, select **Install Add-on From File…** from the gear menu,
  and open the downloaded XPI.
- **Chrome** — Extract the [Chrome ZIP](https://github.com/SebasCH04/Vault-Cleaner/releases/download/v0.3.7/Vault-Cleaner-v0.3.7-Chrome.zip).
  Open `chrome://extensions`, enable **Developer mode**, and use **Load unpacked**
  to select the extracted folder containing `manifest.json`. You can also load
  the repository's [Chrome folder](Chrome/).

Reload DIM after installation and open **Vault Cleaner** in the bottom-right corner.
