# Política de privacidad de Vault Cleaner

Vault Cleaner ayuda a revisar el inventario de Destiny 2 dentro de Destiny Item Manager (DIM). Lee los identificadores de las copias, sus rangos de popularidad, estadísticas, ventajas, ubicación y estado de protección para mostrar comparaciones y preparar lotes.

La extensión utiliza el almacenamiento del navegador para guardar los identificadores de las copias y sus calificaciones, las elecciones del usuario sobre qué copias conservar y el estado de sincronización. El estado de sincronización incluye el identificador de la cuenta activa de DIM para asociar los resultados al inventario correcto. Las calificaciones usadas en la limpieza caducan tras 48 horas. El usuario puede eliminar los datos guardados al desinstalar la extensión.

Para actualizar las calificaciones, Vault Cleaner abre el Roll Appraiser de light.gg usando la sesión de ese navegador y lee el resultado para las copias que coinciden con DIM. Si el usuario confirma una transferencia, la extensión solicita a DIM el traslado de las copias seleccionadas al personaje elegido. El inicio de sesión y las solicitudes de esos sitios se rigen por las políticas de light.gg, DIM y Bungie. El procesamiento de los datos de inventario ocurre en el navegador y su uso se limita a las funciones descritas en esta política.

El diagnóstico que el usuario puede descargar se guarda localmente. Si el usuario decide compartirlo para obtener soporte, contiene contadores y muestras limitadas sobre cómo se leyeron los rangos.
