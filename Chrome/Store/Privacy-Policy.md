# Vault Cleaner Privacy Policy

Vault Cleaner helps users review their Destiny 2 inventory in Destiny Item
Manager (DIM). It reads item instance IDs, popularity ratings, stats, perks,
locations, and protection status to show comparisons and prepare batches.

The extension uses browser storage to save item instance IDs and ratings,
the user's choices of which copies to keep, and the sync status. The sync status
includes the active DIM account ID so results are associated with the correct
inventory. Ratings used for cleanup expire after 48 hours. Users can remove the
saved data by uninstalling the extension.

To update ratings, Vault Cleaner opens the light.gg Roll Appraiser using the
session in that browser and reads the results for copies that match the DIM
inventory. When a user confirms a transfer, the extension asks DIM to move the
selected copies to the chosen character. Sign-ins and requests are governed by
the policies of light.gg, DIM, and Bungie. Inventory data is processed in the
browser and is used solely for the functions described in this policy.

Users can download a diagnostic report to their device. If they choose to share
it for support, it contains counts and limited samples of how ratings were read.
